# BingPaper 开发规格文档（C# / WinUI 3 / Windows AppSDK）

本文档面向 Code Agent，目标是把 `pages/` 中的静态 UI 稿转化为可编译、可运行的 WinUI 3 桌面应用。与上一版不同，这一版以**可直接复制到项目里运行的完整范例**为主，减少纯接口声明，增加真实可跑的代码。

> 配套资料：同目录下 `pages/` 文件夹为静态 UI 稿，包含今日壁纸、下载壁纸、壁纸预览、设置壁纸、关于、软件设置六个页面。Code Agent 应以本文档为功能实现依据，以 `pages/` 为视觉与布局参考。

## 1. 先创建一个能跑起来的项目

### 1.1 推荐技术栈

- **项目模板**：Blank App, Packaged (WinUI 3 in Desktop) / Windows AppSDK 1.6+
- **语言**：C# 11+
- **UI 框架**：WinUI 3 + Windows App SDK
- **辅助库**：
  - `CommunityToolkit.WinUI`（SettingsCard、NavigationView 样式等）
  - `Microsoft.Windows.SDK.BuildTools`
  - `Microsoft.Win32.Registry`
- **配置存储**：`Windows.Storage.ApplicationData.Current.LocalSettings`
- **壁纸设置**：`Windows.System.UserProfile.UserProfilePersonalizationSettings` + P/Invoke `SystemParametersInfo`
- **开机自启**：`Windows.ApplicationModel.StartupTask`
- **网络**：`System.Net.Http.HttpClient`
- **JSON 解析**：`System.Text.Json`

### 2.3 MainWindow.xaml.cs

```csharp
using Microsoft.UI;
using Microsoft.UI.Windowing;
using Microsoft.UI.Xaml;
using Microsoft.UI.Xaml.Controls;
using Microsoft.UI.Xaml.Media;
using System;
using Windows.Graphics;
using BingPaper.Helpers;
using BingPaper.Models;

namespace BingPaper;

public sealed partial class MainWindow : Window
{
    private AppWindow m_AppWindow;

    public MainWindow()
    {
        InitializeComponent();
        ExtendsContentIntoTitleBar = true;
        SetTitleBar(AppTitleBar);

        m_AppWindow = GetAppWindowForCurrentWindow();
        m_AppWindow.Resize(new SizeInt32(1200, 800));

        // 应用材质和主题
        DwmHelper.SetBackdrop(this, App.Settings.Material);
        ApplyTheme(App.Settings.Theme);
    }

    private AppWindow GetAppWindowForCurrentWindow()
    {
        IntPtr hWnd = WinRT.Interop.WindowNative.GetWindowHandle(this);
        WindowId wndId = Win32Interop.GetWindowIdFromWindow(hWnd);
        return AppWindow.GetFromWindowId(wndId);
    }

    private void NavView_Loaded(object sender, RoutedEventArgs e)
    {
        ContentFrame.Navigate(typeof(Views.TodayPage));
    }

    private void NavView_ItemInvoked(NavigationView sender, NavigationViewItemInvokedEventArgs args)
    {
        if (args.InvokedItemContainer is NavigationViewItem item && item.Tag is string tag)
        {
            Type pageType = Type.GetType(tag);
            if (pageType != null && ContentFrame.CurrentSourcePageType != pageType)
            {
                ContentFrame.Navigate(pageType);
            }
        }
    }

    private void PaneToggle_Click(object sender, RoutedEventArgs e)
    {
        NavView.IsPaneOpen = !NavView.IsPaneOpen;
    }

    private void BackButton_Click(object sender, RoutedEventArgs e)
    {
        if (ContentFrame.CanGoBack) ContentFrame.GoBack();
    }

    private void ThemeButton_Click(object sender, RoutedEventArgs e)
    {
        var next = App.Settings.Theme switch
        {
            AppTheme.Dark => AppTheme.Light,
            AppTheme.Light => AppTheme.System,
            _ => AppTheme.Dark
        };
        App.Settings.Theme = next;
        ApplyTheme(next);
        new Services.SettingsService().Save(App.Settings);
    }

    private void ApplyTheme(AppTheme theme)
    {
        if (theme == AppTheme.Dark)
        {
            RequestedTheme = ApplicationTheme.Dark;
        }
        else if (theme == AppTheme.Light)
        {
            RequestedTheme = ApplicationTheme.Light;
        }
        else
        {
            // System：WinUI 3 默认跟随系统，这里不复写 RequestedTheme
        }
    }

    private void MinimizeButton_Click(object sender, RoutedEventArgs e)
    {
        var presenter = m_AppWindow.Presenter as OverlappedPresenter;
        presenter?.Minimize();
    }

    private void MaximizeButton_Click(object sender, RoutedEventArgs e)
    {
        var presenter = m_AppWindow.Presenter as OverlappedPresenter;
        if (presenter?.State == OverlappedPresenterState.Maximized)
            presenter.Restore();
        else
            presenter?.Maximize();
    }

    private void CloseButton_Click(object sender, RoutedEventArgs e)
    {
        Close();
    }
}
```

## 4. Service 层完整实现

### 4.1 SettingsService（配置读写）

```csharp
using Windows.Storage;
using BingPaper.Models;

namespace BingPaper.Services;

public class SettingsService
{
    private readonly ApplicationDataContainer _local = ApplicationData.Current.LocalSettings;

    public AppSettings Load()
    {
        var settings = new AppSettings();

        if (_local.Values["WallpaperPath"] is string path)
            settings.WallpaperPath = path;

        if (_local.Values["Startup"] is bool startup)
            settings.Startup = startup;

        if (_local.Values["RememberWindowSize"] is bool remember)
            settings.RememberWindowSize = remember;

        if (_local.Values["Theme"] is string theme && Enum.TryParse<AppTheme>(theme, out var t))
            settings.Theme = t;

        if (_local.Values["Material"] is string material && Enum.TryParse<AppMaterial>(material, out var m))
            settings.Material = m;

        if (_local.Values["WindowStyle"] is string ws && Enum.TryParse<WindowStyle>(ws, out var w))
            settings.WindowStyle = w;

        if (_local.Values["PlaybackMode"] is string pm && Enum.TryParse<PlaybackMode>(pm, out var p))
            settings.PlaybackMode = p;

        if (_local.Values["Fit"] is string fit && Enum.TryParse<WallpaperFit>(fit, out var f))
            settings.Fit = f;

        if (_local.Values["SwitchInterval"] is string interval && TimeSpan.TryParse(interval, out var si))
            settings.SwitchInterval = si;

        if (_local.Values["Shuffle"] is bool shuffle)
            settings.Shuffle = shuffle;

        if (_local.Values["SetLockScreen"] is bool lockScreen)
            settings.SetLockScreen = lockScreen;

        return settings;
    }

    public void Save(AppSettings settings)
    {
        _local.Values["WallpaperPath"] = settings.WallpaperPath;
        _local.Values["Startup"] = settings.Startup;
        _local.Values["RememberWindowSize"] = settings.RememberWindowSize;
        _local.Values["Theme"] = settings.Theme.ToString();
        _local.Values["Material"] = settings.Material.ToString();
        _local.Values["WindowStyle"] = settings.WindowStyle.ToString();
        _local.Values["PlaybackMode"] = settings.PlaybackMode.ToString();
        _local.Values["Fit"] = settings.Fit.ToString();
        _local.Values["SwitchInterval"] = settings.SwitchInterval.ToString();
        _local.Values["Shuffle"] = settings.Shuffle;
        _local.Values["SetLockScreen"] = settings.SetLockScreen;
    }
}
```

### 4.2 BingWallpaperService（含下载进度）

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Net.Http;
using System.Text.Json;
using System.Threading.Tasks;
using BingPaper.Models;

namespace BingPaper.Services;

public class BingWallpaperService
{
    private readonly HttpClient _http = new();

    public async Task<BingImageInfo> GetTodayAsync(string market = "zh-CN")
    {
        var list = await GetHistoryAsync(0, 1, market);
        return list.FirstOrDefault();
    }

    public async Task<List<BingImageInfo>> GetHistoryAsync(int startIdx, int count, string market = "zh-CN")
    {
        var url = $"https://www.bing.com/HPImageArchive.aspx?format=js&idx={startIdx}&n={count}&mkt={market}";
        try
        {
            var json = await _http.GetStringAsync(url);
            var resp = JsonSerializer.Deserialize<BingApiResponse>(json);
            return resp?.Images ?? new List<BingImageInfo>();
        }
        catch (Exception ex)
        {
            System.Diagnostics.Debug.WriteLine($"Bing API 失败: {ex.Message}");
            return new List<BingImageInfo>();
        }
    }

    public async Task<string> DownloadAsync(BingImageInfo info, string folder, IProgress<double> progress = null)
    {
        Directory.CreateDirectory(folder);
        var url = info.GetUhdUrl();
        var fileName = $"bing_{info.EndDate}.jpg";
        var path = Path.Combine(folder, fileName);

        if (File.Exists(path))
        {
            progress?.Report(1.0);
            return path;
        }

        using var response = await _http.GetAsync(url, HttpCompletionOption.ResponseHeadersRead);
        response.EnsureSuccessStatusCode();

        var total = response.Content.Headers.ContentLength ?? -1L;
        await using var input = await response.Content.ReadAsStreamAsync();
        await using var output = File.Create(path);

        var buffer = new byte[81920];
        long read = 0;
        int bytes;
        while ((bytes = await input.ReadAsync(buffer.AsMemory(0, buffer.Length))) > 0)
        {
            await output.WriteAsync(buffer.AsMemory(0, bytes));
            read += bytes;
            if (total > 0) progress?.Report((double)read / total);
        }

        return path;
    }
}
```

### 4.3 WallpaperService（设置桌面/锁屏 + 幻灯片）

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Runtime.InteropServices;
using System.Threading.Tasks;
using Microsoft.UI.Dispatching;
using Microsoft.Win32;
using Windows.Storage;
using Windows.System.UserProfile;
using BingPaper.Models;

namespace BingPaper.Services;

public class WallpaperService
{
    [DllImport("user32.dll", CharSet = CharSet.Unicode, SetLastError = true)]
    private static extern int SystemParametersInfo(int uAction, int uParam, string lpvParam, int fuWinIni);

    private const int SPI_SETDESKWALLPAPER = 20;
    private const int SPIF_UPDATEINIFILE = 0x01;
    private const int SPIF_SENDCHANGE = 0x02;

    private DispatcherQueueTimer _timer;
    private List<string> _slideshowFiles;
    private int _slideshowIndex;

    public async Task<bool> SetDesktopAsync(string imagePath, WallpaperFit fit)
    {
        if (!File.Exists(imagePath)) return false;
        ApplyFit(fit);
        SystemParametersInfo(SPI_SETDESKWALLPAPER, 0, imagePath, SPIF_UPDATEINIFILE | SPIF_SENDCHANGE);
        return true;
    }

    public async Task<bool> SetLockScreenAsync(string imagePath)
    {
        if (!File.Exists(imagePath)) return false;
        var file = await StorageFile.GetFileFromPathAsync(imagePath);
        return await UserProfilePersonalizationSettings.Current.TrySetLockScreenImageAsync(file);
    }

    private void ApplyFit(WallpaperFit fit)
    {
        using var key = Registry.CurrentUser.OpenSubKey(@"Control Panel\Desktop", true);
        if (key == null) return;

        switch (fit)
        {
            case WallpaperFit.Fill: key.SetValue("WallpaperStyle", "10"); key.SetValue("TileWallpaper", "0"); break;
            case WallpaperFit.Fit: key.SetValue("WallpaperStyle", "6"); key.SetValue("TileWallpaper", "0"); break;
            case WallpaperFit.Stretch: key.SetValue("WallpaperStyle", "2"); key.SetValue("TileWallpaper", "0"); break;
            case WallpaperFit.Tile: key.SetValue("WallpaperStyle", "0"); key.SetValue("TileWallpaper", "1"); break;
            case WallpaperFit.Center: key.SetValue("WallpaperStyle", "0"); key.SetValue("TileWallpaper", "0"); break;
            case WallpaperFit.Span: key.SetValue("WallpaperStyle", "22"); key.SetValue("TileWallpaper", "0"); break;
        }
    }

    public void StartSlideshow(TimeSpan interval, bool shuffle, WallpaperFit fit)
    {
        StopSlideshow();
        var folder = App.Settings.WallpaperPath;
        if (!Directory.Exists(folder)) return;

        _slideshowFiles = Directory.EnumerateFiles(folder, "*.jpg")
            .Concat(Directory.EnumerateFiles(folder, "*.png"))
            .ToList();

        if (_slideshowFiles.Count == 0) return;
        if (shuffle) _slideshowFiles = _slideshowFiles.OrderBy(_ => Guid.NewGuid()).ToList();

        _timer = DispatcherQueue.GetForCurrentThread().CreateTimer();
        _timer.Interval = interval;
        _slideshowIndex = 0;
        _timer.Tick += async (s, e) =>
        {
            _slideshowIndex = (_slideshowIndex + 1) % _slideshowFiles.Count;
            await SetDesktopAsync(_slideshowFiles[_slideshowIndex], fit);
            if (App.Settings.SetLockScreen)
                await SetLockScreenAsync(_slideshowFiles[_slideshowIndex]);
        };
        _timer.Start();
    }

    public void StopSlideshow()
    {
        _timer?.Stop();
        _timer = null;
        _slideshowFiles = null;
    }
}
```

### 4.4 StartupService（开机自启）

```csharp
using System.Threading.Tasks;
using Windows.ApplicationModel;

namespace BingPaper.Services;

public class StartupService
{
    private const string TaskId = "BingPaperStartup";

    public async Task<bool> GetStateAsync()
    {
        var task = await StartupTask.GetAsync(TaskId);
        return task.State == StartupTaskState.Enabled;
    }

    public async Task<bool> EnableAsync()
    {
        var task = await StartupTask.GetAsync(TaskId);
        if (task.State == StartupTaskState.Disabled)
        {
            var state = await task.RequestEnableAsync();
            return state == StartupTaskState.Enabled;
        }
        return true;
    }

    public async Task DisableAsync()
    {
        var task = await StartupTask.GetAsync(TaskId);
        task.Disable();
    }
}
```

### 4.5 UpdateService（检查更新）

```csharp
using System;
using System.Net.Http;
using System.Reflection;
using System.Text.Json;
using System.Threading.Tasks;

namespace BingPaper.Services;

public class UpdateService
{
    private readonly HttpClient _http = new();
    private const string Repo = "SFishNetwork/BingPaper";

    public async Task<(bool HasUpdate, string LatestVersion, string ReleaseUrl)> CheckAsync()
    {
        try
        {
            _http.DefaultRequestHeaders.UserAgent.ParseAdd("BingPaper");
            var json = await _http.GetStringAsync($"https://api.github.com/repos/{Repo}/releases/latest");
            using var doc = JsonDocument.Parse(json);
            var tag = doc.RootElement.GetProperty("tag_name").GetString();
            var url = doc.RootElement.GetProperty("html_url").GetString();
            var current = Assembly.GetExecutingAssembly().GetName().Version?.ToString();
            var hasUpdate = tag != null && tag.TrimStart('v') != current;
            return (hasUpdate, tag, url);
        }
        catch (Exception ex)
        {
            System.Diagnostics.Debug.WriteLine($"检查更新失败: {ex.Message}");
            return (false, null, null);
        }
    }
}
```

```csharp
        AspectBox.ItemsSource = isLandscape
            ? new[] { "UHD(16:9)", "16:9", "16:10", "4:3", "21:9" }
            : new[] { "9:16", "9:18", "3:4" };
        AspectBox.SelectedIndex = 0;

    private void AspectBox_SelectionChanged(object sender, SelectionChangedEventArgs e)
    {
        var aspect = AspectBox.SelectedItem as string ?? "16:9";
        ResolutionBox.ItemsSource = aspect switch
        {
            "UHD(16:9)" => new[] { "3840x2160", "1920x1080" },
            "16:9" => new[] { "1920x1080", "2560x1440", "3840x2160" },
            "16:10" => new[] { "1920x1200", "2560x1600" },
            "4:3" => new[] { "1600x1200", "2048x1536" },
            "21:9" => new[] { "3440x1440", "2560x1080" },
            "9:16" => new[] { "1080x1920", "1440x2560" },
            "9:18" => new[] { "1080x2160", "1440x2880" },
            "3:4" => new[] { "1200x1600", "1536x2048" },
            _ => new[] { "1920x1080" }
        };
        ResolutionBox.SelectedIndex = 0;
    }

    private async void DownloadBtn_Click(object sender, RoutedEventArgs e)
    {
        if (StartDatePicker.Date == null || EndDatePicker.Date == null) return;
        var start = StartDatePicker.Date.Value.DateTime;
        var end = EndDatePicker.Date.Value.DateTime;
        if (start > end)
        {
            StatusText.Text = "开始日期不能晚于结束日期";
            return;
        }

        DownloadBtn.IsEnabled = false;
        ProgressBar.Visibility = Visibility.Visible;
        ProgressBar.IsIndeterminate = true;

        var days = (end - start).Days + 1;
        var total = Math.Min(days, 30);
        var downloaded = 0;

        for (int i = 0; i < total; i++)
        {
            var list = await _bing.GetHistoryAsync(i, 1);
            var info = list.FirstOrDefault();
            if (info == null) continue;

            await _bing.DownloadAsync(info, App.Settings.WallpaperPath);
            downloaded++;
            StatusText.Text = $"已下载 {downloaded}/{total}";
        }

        ProgressBar.Visibility = Visibility.Collapsed;
        DownloadBtn.IsEnabled = true;
        StatusText.Text = $"完成，共下载 {downloaded} 张";
    }
```

```csharp
using Microsoft.UI.Xaml;
using Microsoft.UI.Xaml.Controls;
using Microsoft.UI.Xaml.Media.Imaging;
using System;
using System.Collections.ObjectModel;
using System.IO;
using System.Linq;
using System.Threading.Tasks;
using BingPaper.Models;
using BingPaper.Services;

namespace BingPaper.Views;

public sealed partial class PreviewPage : Page
{
    private readonly WallpaperService _wallpaper = new();
    private ObservableCollection<WallpaperItem> _items = new();

    public PreviewPage()
    {
        InitializeComponent();
        Loaded += PreviewPage_Loaded;
        WallpaperGrid.ItemsSource = _items;
    }

    private async void PreviewPage_Loaded(object sender, RoutedEventArgs e)
    {
        ThemeFilter.ItemsSource = new[] { "全部", "横屏", "竖屏" };
        ThemeFilter.SelectedIndex = 0;
        await LoadImagesAsync();
    }

    private async Task LoadImagesAsync()
    {
        _items.Clear();
        var folder = App.Settings.WallpaperPath;
        if (!Directory.Exists(folder)) return;

        var files = Directory.EnumerateFiles(folder, "*.jpg")
            .Concat(Directory.EnumerateFiles(folder, "*.png"))
            .OrderByDescending(f => new FileInfo(f).CreationTime);

        foreach (var file in files)
        {
            var item = new WallpaperItem
            {
                FilePath = file,
                FileName = Path.GetFileName(file),
                Date = new FileInfo(file).CreationTime
            };

            var bmp = new BitmapImage();
            using var stream = File.OpenRead(file);
            await bmp.SetSourceAsync(stream.AsRandomAccessStream());
            item.Thumbnail = bmp;

            _items.Add(item);
        }
    }

    private void ThemeFilter_SelectionChanged(object sender, SelectionChangedEventArgs e)
    {
        // 简单按文件名或分辨率过滤，实际可按 EXIF 方向
        var filter = ThemeFilter.SelectedItem as string;
        if (filter == "全部")
        {
            WallpaperGrid.ItemsSource = _items;
            return;
        }

        var filtered = filter == "横屏"
            ? _items.Where(i => i.Thumbnail.PixelWidth >= i.Thumbnail.PixelHeight)
            : _items.Where(i => i.Thumbnail.PixelWidth < i.Thumbnail.PixelHeight);

        WallpaperGrid.ItemsSource = new ObservableCollection<WallpaperItem>(filtered);
    }

    private async void WallpaperGrid_ItemClick(object sender, ItemClickEventArgs e)
    {
        if (e.ClickedItem is not WallpaperItem item) return;
        await _wallpaper.SetDesktopAsync(item.FilePath, App.Settings.Fit);
    }
}
```

```csharp
    {
        // 保存设置
        App.Settings.Fit = Enum.Parse<WallpaperFit>(FitBox.SelectedItem as string);
        App.Settings.Shuffle = ShuffleBox.IsChecked ?? false;
        App.Settings.SetLockScreen = LockScreenBox.IsChecked ?? false;
        App.Settings.SwitchInterval = ParseInterval(IntervalBox.SelectedItem as string);

            : PlaybackMode.Today;

        {
            var info = await _bing.GetTodayAsync();
            if (info == null) return;
            var path = await _bing.DownloadAsync(info, App.Settings.WallpaperPath);
            await _wallpaper.SetDesktopAsync(path, App.Settings.Fit);
            if (App.Settings.SetLockScreen)
                await _wallpaper.SetLockScreenAsync(path);

            "1小时" => TimeSpan.FromHours(1),
            "6小时" => TimeSpan.FromHours(6),
            "1天" => TimeSpan.FromDays(1),
```

### 6.1 DwmHelper（材质设置）

```csharp
using System;
using System.Runtime.InteropServices;
using Microsoft.UI;
using Microsoft.UI.Windowing;
using Microsoft.UI.Xaml;
using Windows.Graphics;
using BingPaper.Models;

namespace BingPaper.Helpers;

public static class DwmHelper
{
    [DllImport("dwmapi.dll")]
    private static extern int DwmSetWindowAttribute(IntPtr hwnd, int attr, ref int attrValue, int attrSize);

    private const int DWMWA_SYSTEMBACKDROP_TYPE = 38;

    public static void SetBackdrop(Window window, AppMaterial material)
    {
        var hwnd = WinRT.Interop.WindowNative.GetWindowHandle(window);
        int value = material switch
        {
            AppMaterial.Mica => 2,      // DWMSBT_MAINWINDOW
            AppMaterial.MicaAlt => 4,   // DWMSBT_TABBEDWINDOW
            AppMaterial.Acrylic => 3,   // DWMSBT_TRANSIENTWINDOW
            AppMaterial.Solid => 1,     // DWMSBT_NONE
            _ => 2
        };
        DwmSetWindowAttribute(hwnd, DWMWA_SYSTEMBACKDROP_TYPE, ref value, sizeof(int));
    }
}
```

## 7. 打包与发布

1. **项目类型**：选择 `Packaged (WinUI 3 in Desktop)`，以便使用 `StartupTask` 和 `UserProfilePersonalizationSettings`。
2. **目标平台**：Target 22621，Min 19041。
3. **权限**：
   - 设置壁纸无需额外权限；
   - 锁屏壁纸无需额外权限；
   - 开机自启需在 `Package.appxmanifest` 声明；
   - 访问用户选定的壁纸目录使用 `FolderPicker`，无需 `PicturesLibrary`。
4. **发布**：使用 `msbuild /t:publish` 或 Visual Studio 发布为 MSIX，可侧载或上架 Microsoft Store。
