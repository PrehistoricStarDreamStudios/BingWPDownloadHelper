# BingWPDownloadHelper

## 中文


  ### ℹ 一款带有UI的必应壁纸下载器，采用带Fluent Design的WinUI3框架，目前开发中，设计包含以下功能：展现及下载今日壁纸、下载历史壁纸、一键设置幻灯片放映等
  
  ### 🔒 采用 *GPL-3.0* 许可证，允许进行 *二次编辑、分发* ，但 **不允许** *闭源* ！！！
  
  ### 🤖&📕 编程&法律声明 本程序采用[Github Copilot AI](https://github.com/copilot)辅助生成，api来自[微软Bing](https://cn.bing.com)，list来自[仓库niumoo/bing-wallpaper]([https://](https://github.com/niumoo/bing-wallpaper))并使用[Trae-CN AI](https://trae.com.cn)进行整合，与[微软 Microsoft](https://microsoft.com)没有任何关系，允许使用者自行编译（使用[Visual Studio](https://visualstudio.microsoft.com/zh-hans/vs/)）

  ### ⚠ 温馨提示：该软件还是瞎写的一坨坨屎堆成的屎山，具有薛定谔的不稳定的稳定性，所以出的任何问题本人概不负责！目前设置壁纸仍处于混沌状态，开机自启也是不知道能不能用，等我放暑假了再修改！


###   食用教程：
   前往[Releases](https://github.com/PrehistoricStarDreamStudios/BingWPDownloadHelper/releases)下载你的电脑架构的版本的zip或7z文件，解压后右键install.ps1选择用Powershell运行，按照提示步骤完成即为安装成功。msix由于没有付费签名所以无法直接安装。


  ### ✔ 功能介绍


   #### 🏠 今日壁纸
     打开软件默认为该页面，展示今日壁纸，并显示图片信息，可以选择清晰度

   #### ⬇ 下载壁纸
     可以选择壁纸下载的目录以及清晰度、比例、最大日期期限等
  
   #### ⌛ 历史壁纸
     开发中，暂未实现
   
   #### ⚙ 软件设置
     设置自启、列表源、api源（部分功能正在实现）
